# কর্মপরিকল্পনা ও প্রতিবেদন সিস্টেম — সম্পূর্ণ ফ্রি ডিপ্লয়মেন্ট গাইড

এই গাইডটি ধাপে ধাপে অনুসরণ করলে **কোনো টাকা খরচ ছাড়াই** আপনার সফটওয়্যারটি ইন্টারনেটে লাইভ করতে পারবেন। কোনো কোডিং জ্ঞান দরকার নেই — শুধু ধাপগুলো অনুসরণ করুন।

মোট সময় লাগবে আনুমানিক ৩০-৪৫ মিনিট।

---

## ধাপ ১: Supabase অ্যাকাউন্ট তৈরি (ডেটাবেজ)

1. [supabase.com](https://supabase.com) এ যান এবং **Start your project** ক্লিক করুন
2. GitHub বা ইমেইল দিয়ে সাইন আপ করুন (সম্পূর্ণ ফ্রি)
3. **New Project** ক্লিক করুন
   - Name: `ngo-work-plan` (যেকোনো নাম)
   - Database Password: একটি শক্তিশালী পাসওয়ার্ড দিন এবং **সেভ করে রাখুন**
   - Region: Singapore বা যেটা সবচেয়ে কাছে দেখায় সেটা বেছে নিন
4. প্রজেক্ট তৈরি হতে ১-২ মিনিট সময় লাগবে

### ডেটাবেজ টেবিল তৈরি করা
1. বাম পাশের মেনু থেকে **SQL Editor** ক্লিক করুন
2. **New query** ক্লিক করুন
3. এই প্রজেক্টের `supabase-schema.sql` ফাইলটি খুলুন, পুরো কনটেন্ট কপি করুন
4. SQL Editor-এ পেস্ট করে **Run** বাটনে ক্লিক করুন
5. "Success" মেসেজ দেখলে বুঝবেন সব টেবিল তৈরি হয়ে গেছে

### API কী সংগ্রহ করা
1. বাম মেনু থেকে **Project Settings → API** এ যান
2. এই তিনটি মান কপি করে নোটপ্যাডে রাখুন:
   - **Project URL** (যেমন: `https://xxxxx.supabase.co`)
   - **anon public** কী
   - **service_role** কী (⚠️ এটি কাউকে শেয়ার করবেন না)

## ধাপ ২: কোড GitHub-এ আপলোড করা

1. [github.com](https://github.com) এ ফ্রি অ্যাকাউন্ট তৈরি করুন
2. **New repository** ক্লিক করুন, নাম দিন `ngo-work-plan-system`, **Private** সিলেক্ট করুন, **Create repository**
3. এই প্রজেক্টের সবগুলো ফাইল/ফোল্ডার ডাউনলোড করে রাখা zip থেকে বের করুন
4. GitHub রিপোজিটরি পেজে **uploading an existing file** লিংকে ক্লিক করুন
5. সবগুলো ফাইল ও ফোল্ডার টেনে এনে (drag & drop) আপলোড করুন এবং **Commit changes** ক্লিক করুন

*(টিপ: ফাইল বেশি হলে GitHub Desktop অ্যাপ ব্যবহার করলে সহজ হয় — [desktop.github.com](https://desktop.github.com))*

## ধাপ ৩: Vercel-এ ফ্রি হোস্টিং

1. [vercel.com](https://vercel.com) এ যান, **Sign Up** করুন — GitHub অ্যাকাউন্ট দিয়ে সাইন ইন করাই সহজ
2. **Add New → Project** ক্লিক করুন
3. আপনার `ngo-work-plan-system` রিপোজিটরি খুঁজে **Import** করুন
4. **Environment Variables** সেকশনে ধাপ ১ থেকে সংগ্রহ করা তিনটি মান যোগ করুন:

   | Name | Value |
   |---|---|
   | `NEXT_PUBLIC_SUPABASE_URL` | আপনার Project URL |
   | `NEXT_PUBLIC_SUPABASE_ANON_KEY` | আপনার anon public কী |
   | `SUPABASE_SERVICE_ROLE_KEY` | আপনার service_role কী |

5. **Deploy** বাটনে ক্লিক করুন — ২-৩ মিনিট অপেক্ষা করুন
6. ডিপ্লয় শেষ হলে আপনি একটি লিংক পাবেন, যেমন: `https://ngo-work-plan-system.vercel.app` — এটাই আপনার সফটওয়্যারের ঠিকানা, সম্পূর্ণ ফ্রি!

## ধাপ ৪: প্রথম অ্যাডমিন অ্যাকাউন্ট তৈরি

সিস্টেমে নতুন ইউজার শুধু অ্যাডমিন তৈরি করতে পারবেন — তাই প্রথম অ্যাডমিনটি ম্যানুয়ালি তৈরি করতে হবে:

1. Supabase-এ ফিরে যান → বাম মেনু থেকে **Authentication → Users**
2. **Add user → Create new user** ক্লিক করুন
   - Email: `admin@ngo.local`
   - Password: একটি শক্তিশালী পাসওয়ার্ড দিন
   - **Auto Confirm User** চেক করুন
   - **Create user** ক্লিক করুন
3. তৈরি হওয়া ইউজারের **User UID** কপি করুন (লম্বা একটি কোড)
4. বাম মেনু থেকে **SQL Editor → New query**, নিচের কোড পেস্ট করুন (UID এবং নাম বদলে দিন):

```sql
insert into profiles (id, employee_code, full_name, designation, is_admin)
values ('এখানে-UID-পেস্ট-করুন', 'admin', 'সিস্টেম অ্যাডমিন', 'other', true);
```

5. **Run** ক্লিক করুন

এখন আপনার লাইভ ওয়েবসাইটে গিয়ে ইউজার আইডি `admin` ও আপনার দেওয়া পাসওয়ার্ড দিয়ে লগইন করুন। অ্যাডমিন প্যানেল থেকে বাকি ২০০-৩০০ জনের অ্যাকাউন্ট তৈরি করতে পারবেন।

## ধাপ ৫ (ঐচ্ছিক): SMS নোটিফিকেশন চালু করা

সিস্টেমে দুই জায়গায় SMS পাঠানোর ব্যবস্থা আছে:
- নতুন পরিকল্পনা জমা পড়লে → সুপিরিয়রকে SMS
- পরিকল্পনা Approve/Reject হলে → সংশ্লিষ্ট কর্মকর্তাকে SMS

**⚠️ গুরুত্বপূর্ণ:** SMS পাঠানো সম্পূর্ণ ফ্রি নয় — প্রতিটি SMS-এর জন্য গেটওয়ে প্রোভাইডারকে সামান্য টাকা (সাধারণত প্রতি SMS ৩০-৫০ পয়সা) দিতে হয়। এই অংশ স্কিপ করলে বাকি সব ফিচার স্বাভাবিকভাবে কাজ করবে, শুধু SMS যাবে না।

চালু করতে চাইলে:
1. যেকোনো একটি বাংলাদেশি SMS গেটওয়েতে অ্যাকাউন্ট খুলুন এবং প্রিপেইড ব্যালেন্স রিচার্জ করুন — যেমন [bulksmsbd.net](https://bulksmsbd.net), SSL Wireless, বা REVE Systems
2. তাদের কাছ থেকে **API Key** ও **Sender ID** সংগ্রহ করুন
3. Vercel প্রজেক্টের **Settings → Environment Variables**-এ গিয়ে যোগ করুন:
   - `SMS_API_KEY`
   - `SMS_SENDER_ID`
4. **Redeploy** ক্লিক করুন

*(অন্য কোনো গেটওয়ে ব্যবহার করতে চাইলে জানাবেন — `lib/sms.ts` ফাইলটি সেই গেটওয়ের জন্য বদলে দেব।)*

অ্যাডমিন প্যানেল থেকে ইউজার তৈরি করার সময় তাদের মোবাইল নম্বর দিতে ভুলবেন না — নম্বর না থাকলে সেই ইউজারের কাছে SMS যাবে না।

## প্রতিদিনের ব্যবহার

- **অ্যাডমিন**: প্রতিটি কর্মকর্তার জন্য ইউজার আইডি ও অস্থায়ী পাসওয়ার্ড তৈরি করে দেবেন, এবং কার সুপিরিয়র কে হবে তা সেট করবেন
- **কর্মকর্তারা**: প্রতি মাসের শুরুতে পরিকল্পনা জমা দেবেন, প্রতিদিন কাজ এন্ট্রি দেবেন
- **সুপিরিয়ররা**: পরিকল্পনা Approve/Reject করবেন এবং অধীনস্থদের প্রতিবেদন দেখবেন
